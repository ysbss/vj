================================================================================
              DS 人声分离 · 歌词对齐工具 - 使用说明
================================================================================

【软件功能】
  批量处理歌曲/视频：AI（Demucs）分离人声与伴奏，并可选用歌词文件生成
  带时间轴的 LRC 与三语 TXT（日文 / 罗马音 / 中文）。
  无需自行安装 Python、Java、FFmpeg，解压即用。


【系统要求】
  - 操作系统：Windows 10 / 11（64 位）
  - 内存：建议 8 GB 及以上
  - 磁盘：软件本体约 2～4 GB；输出 flac 与模型缓存另计
  - 处理器：支持 CPU；有 NVIDIA 显卡且已安装 GPU 版依赖时自动加速
  - 显卡（可选）：NVIDIA 独显 + 较新驱动，可显著缩短 Demucs / Whisper 耗时
  - 网络：首次运行需联网下载 AI 模型（仅第一次，之后多用系统缓存）
      · Demucs 人声分离：约几百 MB
      · 歌词对齐（若使用）：Whisper medium 约 1.5 GB
  - 歌词翻译：需配置豆包 API Key（见下方「豆包 Key 配置」）


【文件夹说明】
  DS.exe              主程序，双击运行
  input_objects\      放入待处理任务（每首歌一个子文件夹，见下方结构）
  output_objects\     处理结果输出目录
  doubao_ex.txt       豆包 Key 配置示例（需自行改名并填入 Key）
  ffmpeg\             内置音视频工具，请勿删除
  python\             内置 AI 运行环境，请勿删除
  scripts\            内置歌词脚本，请勿删除
  app.log             运行日志，出问题时请打开查看


【input_objects 目录结构】
  每一首歌（或每一个任务）单独建一个子文件夹，例如：

    input_objects\
      └── Wonderland\
            ├── song.mp4          （或 .flac / .mp3 / .wav 等）
            └── lyrics.txt        （可选，一行一句日文歌词）

  支持的媒体格式：mp4、mkv、webm、avi、mov、flv、m4v、m4a、aac、wav、ogg、flac、mp3

  说明：
  - 子文件夹内放至少一个媒体文件；若有多个，程序按文件名取第一个并打日志
  - 若需要 LRC/TXT，在同一文件夹内再放任意名称的 .txt 歌词文件
  - 若没有 .txt，程序只做 Demucs 分离，不跑歌词对齐


【豆包 Key 配置（使用歌词功能时必需）】
  安装包内不含真实 API Key。请按开发者私发的方式获取 Key 后：

  1. 打开与 DS.exe 同目录下的 doubao_ex.txt
  2. 删除说明文字，只保留一行 API Key
  3. 保存后，将文件改名为 doubao.txt（与 DS.exe 同级）

  也可直接新建 doubao.txt，内容为一行 Key，无需 doubao_ex.txt。

  未配置 doubao.txt 时：
  - 无人声歌词文件：仍可正常输出人声/伴奏 flac
  - 有歌词 .txt：Demucs 仍会完成，但 LRC/TXT 生成会失败（见 app.log）


【使用步骤】
  1. 将整个 DS 文件夹解压到任意位置
     建议路径简洁，例如：D:\DS

  2. （可选）按上文配置 doubao.txt

  3. 在 input_objects 下为每首歌建子文件夹，放入媒体文件与歌词 txt

  4. 双击 DS.exe
     会弹出黑色控制台窗口，显示处理进度

  5. 耐心等待
     AI 分离较耗时，歌曲越长越久，CPU 占用高属正常

  6. 到 output_objects\{任务名}\ 查看成品，例如：

       output_objects\Wonderland\
         ├── song-vocals.flac          人声音轨
         ├── song-no_vocals.flac       伴奏音轨
         ├── Wonderland-out_lrc.lrc      歌词时间轴（需有 txt + doubao.txt）
         └── Wonderland-out_txt.txt      三语文本（需有 txt + doubao.txt）

  7. 全部任务完成后，控制台提示「按回车键退出...」，按回车关闭窗口


【注意事项】
  - 可同时在 input_objects 下放多个任务文件夹，程序按顺序逐个处理
  - 再次运行会覆盖 output_objects 中同名输出文件
  - 处理过程中请勿打开正在写入的输出文件
  - 不要删除或移动 python、ffmpeg、scripts 文件夹
  - doubao.txt 请勿外传或上传到公开网盘；压缩包可分享，Key 请单独保管


【常见问题】

  Q：提示 input_objects 里没有子目录？
  A：需要在 input_objects 下新建文件夹（如 歌名\），不能把媒体直接丢在 input_objects 根目录。

  Q：只有 flac，没有 lrc/txt？
  A：检查该任务文件夹内是否有 .txt 歌词，以及 DS.exe 同级是否有 doubao.txt；
     打开 app.log 查看「节点二」是否报错。

  Q：处理很慢？
  A：若无 NVIDIA 显卡或未装 GPU 版 Python 依赖，会使用 CPU，较慢属正常；
     启动时日志若显示「GPU 加速已启用」说明已在用显卡。

  Q：如何确认是否用了 GPU？
  A：运行 DS.exe 后看控制台 / app.log 开头：
     「GPU 加速已启用（显卡名）」= 已加速；
     「未检测到可用 GPU，使用 CPU 推理」= CPU 模式。

  Q：第一次运行很久没反应？
  A：可能正在下载 Demucs 或 Whisper 模型，请保持网络畅通并继续等待；
     下载完成后同机再次运行一般无需重复下载。

  Q：处理失败怎么办？
  A：打开 app.log 查看最后几行报错，将日志发给开发者排查。

  Q：杀毒软件报警？
  A：本软件内含 Python 与 FFmpeg 等组件，部分杀毒软件可能误报；
     请将整个 DS 文件夹加入信任/白名单后重试。
